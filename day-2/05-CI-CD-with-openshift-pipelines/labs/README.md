
# OpenShift Pipelines

## Prerequisites

Make sure you have the following tools installed and configured before starting:

- **GitLab account** - required to fork the demo repository
- **Docker** - to build and push container images locally
- **CRC (OpenShift Local)** - a running local OpenShift cluster
- **oc CLI** - OpenShift command-line tool, logged in to your cluster

## Make a fork

Make a fork of [https://gitlab.com/alexandermamaniy/openshift-demo](https://gitlab.com/alexandermamaniy/openshift-demo) on GitLab.

## Clone your own fork

```bash
git clone https://gitlab.com/<your-username>/openshift-demo.git
cd openshift-demo
```

## Follow the lab steps

Follow the steps in your own fork repository's README.
